What is FBRP?

Fun Border Roleplay is a Roblox roleplay server focused on realistic border scenarios — customs checks, patrols, and everyday life on both sides of the border.

01

Serious Roleplay

We value realistic, high-quality roleplay. Follow the rules, stay in character, and make every scene count.

02

Active Staff Team

Our trained staff team keeps sessions fair and fun — hosting STS events, handling mod calls, and enforcing the rules.

03

Community First

Weekly promotions, server events, and an active Discord. There's always something happening at the border.

How to join

Getting into a session takes less than two minutes.

Step 1

Open ER:LC

Launch Emergency Response: Liberty County on Roblox and open the private server join box.

Step 2

Enter the code

Type in the FBRP server code below and join the session.

Step 3

Follow the STS

Attend the server training session (STS), pick your border, and start your roleplay.

Private server code

Emergency Response: Liberty County — click to copy, then paste it in-game.
